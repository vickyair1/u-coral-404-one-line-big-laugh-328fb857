# One Line, Big Laugh — The Self-Checkout Confession

> "I confessed to the self-checkout that I was stealing, and it asked if I wanted a bag for that."

One original funny line (94 chars), delivered as a deterministic Python program.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (no trailing newline) and prints it to stdout.
